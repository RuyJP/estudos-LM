Resumos Estruturados do Assunto

A Essência: Lógica vs. Algoritmo

Lógica de Programação: É definida como a organização do pensamento e o "jeito certo" de estruturar instruções para que um computador execute uma tarefa.

Ela funciona como uma gramática universal, permitindo que o conhecimento seja transferido entre diferentes linguagens de programação.

Algoritmo: É a aplicação prática da lógica em uma sequência finita de passos ou instruções claras (como uma receita de bolo) para resolver um problema específico.

Um algoritmo não precisa estar em código; ele pode ser uma rotina diária ou um manual de instruções.

Os Pilares da Construção Técnica

Para que um algoritmo funcione, ele utiliza quatro conceitos obrigatórios que "adestram" a máquina:

Variáveis: Espaços na memória RAM para guardar dados (como nomes ou números) que mudam conforme a execução.

Condicionais (If/Else): Filtros de decisão que permitem ao programa responder de forma dinâmica (Ex: se idade < 18, negar acesso).

Estruturas de Repetição (Loops): Comandos (for, while) que automatizam tarefas repetitivas até que um objetivo seja atingido, garantindo escala ao software.

Coleções (Listas/Arrays): Agrupamentos de múltiplos valores em um só lugar, facilitando o processamento de grandes volumes de dados.

Eficiência e Resolução de Problemas

Análise Crítica: Antes de codar, o programador deve entender o problema profundamente.

O Método dos 5Qs (Entrada, Processamento, Restrições, Resultado e Sequência) é a estratégia recomendada para planejar a solução.

Desempenho (Big O): A eficiência de um algoritmo é medida pela Notação Big O, que avalia como o tempo de execução cresce conforme o volume de dados aumenta.

Algoritmos como a Busca Binária (O(logn)) são exponencialmente mais rápidos que a Busca Linear (O(n)) em grandes listas.

--------------------------------------------------------------------------------
Glossário de Principais Conceitos

Big O: Notação matemática usada para classificar e comparar a performance/escalabilidade de algoritmos.

Boolean (Booleano): Tipo de dado que admite apenas dois valores: Verdadeiro (True) ou Falso (False), servindo de base para tomadas de decisão.

Busca Binária: Algoritmo de "dividir para conquistar" que encontra um item em uma lista ordenada dividindo-a repetidamente ao meio.

Concatenação: Processo de juntar diferentes tipos de dados (como um texto e uma variável) para exibição na tela.

Fluxograma: Representação gráfica de um algoritmo usando símbolos padronizados (como losangos para decisões).

Identação: Espaçamento no início das linhas de código que organiza a hierarquia das instruções, essencial para a leitura e funcionamento em linguagens como Python.

Pseudocódigo (Portugol): Descrição dos passos de um algoritmo em linguagem natural (português/inglês), sem as travas técnicas de uma linguagem real.

String: Nome técnico dado a dados do tipo texto na programação.

Teste de Mesa: Processo manual de seguir os passos de um algoritmo no papel para verificar se a lógica está correta antes da execução real.
